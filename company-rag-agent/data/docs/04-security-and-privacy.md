# Security and Data Privacy FAQ

## Where is data stored?
All customer data is stored in data centres in **Frankfurt, Germany** (primary) with an encrypted backup in **Amsterdam, Netherlands**. Enterprise customers can choose EU-only processing with no sub-processors outside the EU.

## Encryption
Data is encrypted in transit with TLS 1.3 and at rest with AES-256. Credentials stored in workflows are encrypted with a per-workspace key.

## Certifications
Nimbus Flow is **ISO 27001** certified and completed a **SOC 2 Type II** audit in 2025. The reports are available to customers under NDA.

## GDPR
Nimbus Flow acts as a data processor. A Data Processing Agreement (DPA) is available in **Settings → Legal** and can be signed electronically. Data subject requests are answered within 30 days.

## Backups
Backups run every **6 hours** and are kept for **35 days**. Point-in-time restore is available for Enterprise customers.

## Access by employees
Nimbus Flow employees can access customer workspaces only when a customer opens a support ticket and grants temporary access. All access is logged and the customer can see the log.

## Reporting a vulnerability
Security issues can be reported to security@nimbusflow.example. Nimbus Flow runs a responsible-disclosure program and answers within 3 business days.
